DATABASE SCHEMA
================================================================================

New Tables:

  carts
    id (INT, PRIMARY KEY)
    user_id (INT, UNIQUE, FOREIGN KEY → users)
    created_at (TIMESTAMP)
    updated_at (TIMESTAMP)

  cart_items
    id (INT, PRIMARY KEY)
    cart_id (INT, FOREIGN KEY → carts)
    product_id (INT, FOREIGN KEY → products)
    qty (INT)
    size (VARCHAR)
    added_at (TIMESTAMP)
    UNIQUE(cart_id, product_id, size)

  saved_items
    id (INT, PRIMARY KEY)
    user_id (INT, FOREIGN KEY → users)
    product_id (INT, FOREIGN KEY → products)
    size (VARCHAR)
    saved_at (TIMESTAMP)
    UNIQUE(user_id, product_id, size)

Foreign Keys:
  carts.user_id → users.id (CASCADE DELETE)
  cart_items.cart_id → carts.id (CASCADE DELETE)
  cart_items.product_id → products.id (CASCADE DELETE)
  saved_items.user_id → users.id (CASCADE DELETE)
  saved_items.product_id → products.id (CASCADE DELETE)

Indexes:
  idx_orders_user_created
  idx_orders_status_created
  idx_pimg_product_sort
  idx_products_category
  idx_order_items_order
  idx_payments_order
  idx_shipments_order

================================================================================
DATA FLOW EXAMPLES
================================================================================

User Registration:
  Frontend: Register Form
    ↓
  AuthHub.handleRegister() [async]
    ↓
  AuthController.register() [async]
    ↓
  UserModel.register() [async]
    ↓
  api.post('/api/register') [with JWT in header]
    ↓
  Backend: AuthController.register()
    ↓
  Backend: UserModel.create() [with BCrypt hashing]
    ↓
  Database: INSERT INTO users
    ↓
  JWT::encode() [create token]
    ↓
  Response: { token, user }
    ↓
  Frontend: Store token in rb_token_v1
    ↓
  Frontend: Cache user in rb_current_user
    ↓
  Navigation: redirect to home

Add to Cart:
  Frontend: Cart Form
    ↓
  CartController.add() [async]
    ↓
  If authenticated:
    ├─ CartModel.addItem() [with backend API]
    │   ↓
    │   api.post('/api/cart/items', {productId, qty, size})
    │   [Includes Authorization: Bearer {token}]
    │   ↓
    │   Backend: CartController.addItem()
    │   ├─ CartModel.getOrCreate(userId)
    │   ├─ CartModel.addItem() [merge quantities]
    │   └─ Return full cart with product data
    │
    └─ Frontend: Update component state

  Else (guest):
    └─ localStorage fallback
        └─ Load rb_cart_local
        └─ Merge item or append
        └─ Save updated cart
